# KnockOff GWAS Pipeline

This repository provides a pipeline for running KnockoffGWAS analyses, building on the [original method](https://msesia.github.io/knockoffgwas/) developed by Matteo Sesia et. al.

## Overview

KnockoffGWAS is a framework for genome-wide association studies that identifies genetic variants while controlling the false discovery rate (FDR) using synthetic knockoff variables. This pipeline streamlines applying the method to real datasets using standard GWAS data.

## Workflow

1. Prepare genotype data
2. Generate knockoff variables
3. Run association tests
4. Analyse findings

## Documentation

For instructions on how to apply the pipeline, please read the user guide: [https://knockoff-gwas.readthedocs.io/](https://knockoff-gwas.readthedocs.io/)
